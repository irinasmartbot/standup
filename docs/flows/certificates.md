# Обычный сертификат

Бот не выдаёт свои номера. Номер `MSS-000001` создаёт страница сайта, бот забирает его по ссылке `msscert_...` и дальше вызывает реестр `https://moscowstandupshow.ru/wp-json/mss-cert/v1/`.

В этой ветке только обычный сертификат: двое гостей, одна дата, формат Хитлото, BEST или Елка для взрослых. Джекпот, отметка «забрали бланк» и «не пришёл» не делаются.

Ключи `CERT_BOT_TOKEN` и `CERT_STAFF_TOKEN` лежат только в `.env` на сервере. Пока их нет, бот просит написать менеджеру и бронь не создаёт.

На одно шоу не больше двух броней с форматом `certificate`. Если мест нет, гость видит: «на указанную дату бесплатных мест по сертификату не осталось».

Фото уходит в тот же чат модерации, что скрины розыгрыша. Там «ПРИНЯТЬ», «ОТКЛОНИТЬ без комментария» и «ОТКЛОНИТЬ с комментарием».

После принятия гость видит живые экраны: выбор формата, постер формата с датами в два ряда, карточку шоу с «Забронировать», затем карточку брони с форматом и датой. Предыдущие сообщения бота в этом шаге удаляются.

Подтверждение списывает номер на сайте. Отмена и просрочка до подтверждения номер не тратят. Если дату скрыли в админке, неподтверждённую бронь бот снимает и на сайте тоже. Подтверждённый номер уже списан — вернуть его может только отмена шоу организатором, её в этой ветке нет. Билет картинкой не отправляется: на входе нужен бумажный сертификат.
