## 2026-07-24 — Перенести регламент в будущую ветку main

Статус: accepted
Владелец решения: Ирина
Связано с: `AGENTS.md`, `docs/agent-regulation.md`, ветка `docs/agent-regulation`

Описание:
Не мержить регламент в текущую ветку `dev`, потому что push/merge в `dev` запускает deploy на VPS. Когда рабочей веткой проекта станет `main`, перенести туда коммит с регламентом.

Зачем:
Нужно применить регламент к основной рабочей ветке проекта без лишнего production-деплоя из `dev`.

Границы:
- Входит: merge ветки `docs/agent-regulation` в `main` или cherry-pick коммита `c3096da`.
- Не входит: merge в `dev`, push в deploy-ветку, изменение workflow деплоя.

Риски и вопросы:
- Перед переносом нужно проверить, какая ветка запускает production-деплой на тот момент.
- Если workflow будет перенесен с `dev` на `main`, merge в `main` тоже может запускать deploy и потребует отдельного разрешения.

## 2026-07-24 — Стабилизационный PR по P0-находкам аудита

Статус: proposed
Владелец решения: не назначен
Связано с: `docs/technical-audit-2026-07-24.md`

Описание:
Подготовить отдельный stabilization PR без новых продуктовых функций, чтобы закрыть P0-находки технического аудита.

## 2026-09-18 — Рассылка: шаблон BEST подставляет время и площадку по выбранному шоу

Статус: done
Владелец решения: Ирина
Связано с: вкладка «Рассылка», шаблоны `best_tg` / `best_vk`, афиша BEST

Описание:
При выборе шаблона BEST TG или BEST VK отметить шоу (например «20 сентября»). Текст письма заполняется временем и адресом этой даты из афиши. Обычно четверг — Escobar 20:00, воскресенье — Temple Bar 19:00; источником служит афиша, а не жёсткая таблица дней недели. Если шоу сегодня — формулировка «сегодня», иначе дата.

Зачем:
Сейчас в шаблоне зашиты Эскобар и 20:00. На Temple Bar в 19:00 текст каждый раз правят руками.

Границы:
- Входит: выбор ближайшего BEST-шоу при подстановке шаблона, плейсхолдеры времени/площадки/адреса, формулировка «сегодня» vs дата.
- Не входит: шаблоны Музлото, автоотправка в день шоу, смена аудитории.

Риски и вопросы:
- Сохранённые в БД тексты шаблонов нужно один раз привести к плейсхолдерам, иначе подстановка не сработает.
- Если на дату нет шоу в афише — шаблон не подставлять вслепую.

Риски и вопросы:
- Нужна миграция CHECK `events.format` и `bookings.format`.
- Старые URL 15.09 остаются «шоу уже прошло».
