# Документация проекта

Эта страница задает порядок чтения документации для проекта Moscow StandUp Show Telegram Bot.

## Быстрый вход

1. `README.md` — назначение проекта, запуск бота и админки.
2. `AGENTS.md` — обязательные правила работы агентов и технических специалистов.
3. `docs/19-current-state.md` — фактическое состояние реализации.
4. `docs/project-passport.md` — команды, окружения, владельцы данных и ограничения.
5. `docs/change-requests.md` — идеи и расширения вне текущего объема.
6. `docs/18-decision-log.md` — принятые важные решения и последствия.

## Технические документы

- `docs/architecture.md` — архитектура, компоненты, переменные окружения и потоки данных.
- `docs/database.md` — модель данных, правила хранения и PostgreSQL-схема.
- `docs/vk_mvp.md` — MVP по VK-направлению.
- `docs/flows/proverka_materiala.md` — пользовательский flow проверки материала.

## Регламент

- `docs/agent-regulation.md` — примененный к проекту регламент работы AI-агентов и технических специалистов.

Полный внешний исходник регламента был перенесен в проект в сокращенном прикладном виде. Если правила противоречат фактическому коду или production, нужно установить причину расхождения и обновить документы в рамках отдельной задачи.
